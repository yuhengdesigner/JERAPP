# JER: Johor Emergency Response App

JER (Johor Emergency Response) is an Android-based emergency response application designed to improve emergency accessibility and response efficiency across Johor. The application enables users to dispatch emergency alerts, receive emergency guidance and access emergency resources through a mobile platform.

## Purpose

The purpose of JER is to provide a centralised platform for Johor citizens and tourists to seek emergency assistance while improving communication between users and emergency service departments.

## Aim

To develop a mobile emergency response application that instantly connects users with the selected emergency departments and provides basic emergency tutorials and guidance during emergent situations.

## Project Overview

JER allows registered users to send emergency alerts, track emergency responses from department, view estimated arrival times (ETA) and access emergency history and details. Guest users can use selected emergency resources without registration, while emergency service department administrators can monitor, receive, process and resolve incoming alerts in real time. The application also provides offline emergency tutorials and guidance such as SOS Flashlight, CPR tutorials, step-by-step emergency guides and daily-encounter critical situations to assist users before professional help arrives.

## Key Features

* One-Tap Emergency Dispatch to Selected Emergency Service Departments
* Real-Time Emergency Tracking and ETA Viewing
* Emergency History and Details can be Viewed Back According to Selected Filters
* Guest User Emergency Access
* Categorised Emergency Services Department Directory
* Offline Emergency Step-by-step Guidance
* SOS Flashlight with Morse Code ". . . _ _ _ . . ."
* CPR Tutorials (Adult, Child, Infant, and Neonate)
* Daily-encounter Emergency Tutorials
* Real-Time Admin Alert Dashboard with Loud Ringtone Alert
* Emergency Case Processing and Completion

## Technologies Used

* **Platform:** Android
* **Programming Language:** Java (Logic), XML (UI)
* **Framework:** Android SDK
* **Database:** Firebase Realtime Database
* **Authentication:** Firebase Authentication
* **Notification Service:** Firebase Cloud Messaging (FCM)
* **Development Methodology:** Agile Scrum
* **Version Control:** GitHub
* **Project Management:** Taiga and Swift Board
* **Deployment Platform:** https://vercel.com/
* **Website To Download APK:** https://jerapp.vercel.app/

## Limitation

IOS devices are not applicable to download JER App. Only Android devices are able to download due to the version uploaded is in Android Package Kit (APK) file, since we develop this system using Android Studio. However, if this system requires further development, our team will try to do IOS and website versions to suit public needs.

## User Roles

| Role | Main Access |
| --- | --- |
| Registered User | Send emergency alerts, track responses, view ETA and history, manage profile, access offline emergency tools |
| Guest User | Browse emergency resources, use SOS Flashlight, access emergency tutorials and contact departments |
| Department Admin | Monitor incoming alerts, process emergencies, resolve cases, and review alert history |
